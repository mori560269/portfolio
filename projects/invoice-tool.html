Project

請求書作成ツール

広告費データ（BigQuery）と請求ルールから請求書を自動作成し、会計サービスへ登録する社内向けWebアプリです。インターン先で開発を担当しました。

  • TypeScript
  • React
  • Drizzle ORM
  • Cloudflare Workers
  • Cloudflare D1
  • BigQuery
  • GitHub Actions

構成

主な機能

  • 広告費データの取得と金額計算
  • 請求書の確認・編集と、作成結果の一覧・履歴管理
  • 本番送信とは別に、事前確認用の「空打ち」モードを用意
  • 生成履歴のCSV出力

設計の工夫

  • 二重発行の防止：請求書ごとにロックを取り、確定まで処理が重ならないようにしました。
  • ビジネスロジックの分離：金額計算や日付処理を純粋関数に分け、ユニットテストで検証できるようにしました。
  • キャッシュの確定管理：広告費データは確定後のみ保存し、再計算を減らしました。
  • 秘密情報の管理：APIキーなどは Cloudflare Secrets に保管し、コードには含めていません。

技術スタック

  • フロントエンド：React 19、Next.js 互換（vinext）、Vite
  • バックエンド：Cloudflare Workers、TypeScript（API Routes）
  • データ：Cloudflare D1（SQLite）、Drizzle ORM
  • 認証：Google OAuth 2.0、署名付きセッション Cookie
  • 外部連携：BigQuery、Google Calendar、サービスアカウント（JWT）
  • 開発・デプロイ：GitHub、GitHub Actions（CI・手動デプロイ）、wrangler
