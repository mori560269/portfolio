# Portfolio

個人ポートフォリオの静的サイトです。HTML / CSS のみで構成しており、ビルドツールは不要です。

## 構成

```
.
├── index.html   # ページ本体（自己紹介・制作物・連絡先）
├── style.css    # スタイルシート
└── README.md
```

## 使い方

1. 下の「記入箇所ガイド」に沿って `index.html` の内容を自分の情報に書き換えます。
2. `style.css` の `:root` 内の色変数で配色を調整できます。
3. ブラウザで `index.html` を開いて表示を確認します。

## 記入箇所ガイド（`index.html`）

| 行 | 場所 | 書くこと |
| --- | --- | --- |
| 6 | `<title>` | ページのタブ名（例：`山田太郎 | Portfolio`） |
| 7 | `<meta name="description">` | 検索結果に出る説明文 |
| 28 | ヒーロー見出し（`h1`） | 名前を含む挨拶 |
| 29 | ヒーローの一行（`.lead`） | 得意分野・興味のある領域 |
| 37 | About の本文 | 経歴、スキル、考え方 |
| 39–41 | スキル一覧（`li`） | スキル名（増減可） |
| 51–53 | 制作物 1（`Project Title 1`） | タイトル・概要・詳細リンク（`href`） |
| 56–58 | 制作物 2 | 同上 |
| 61–63 | 制作物 3 | 同上（カードは `<article class="card">` の単位で増減可） |
| 72 | Contact の文言 | 依頼・問い合わせの案内 |
| 74 | メールアドレス | `mailto:` の後と表示テキストの両方 |
| 75 | GitHub などの SNS リンク | `href` とアカウント名 |
| 83 | フッター | 名前と年 |

制作物の詳細リンクは現状 `href="#"` です。実際のページや GitHub リポジトリの URL に置き換えてください。

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages** を開きます。
2. **Source** を `Deploy from a branch`、Branch を `main` / `(root)` に設定します。
3. 数分後、`https://<ユーザー名>.github.io/portfolio/` で公開されます。
